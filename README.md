# Abhinav Sharma - Premium Cinematic Portfolio

A modern, luxurious portfolio website built with React, Vite, and cutting-edge UI animations.

## 🎯 Features

- ✨ **Cinematic Design** - Dark moonlit aesthetic with water reflection vibes
- 🎥 **Video Hero** - Fullscreen animated background with parallax effect
- 🎨 **Glassmorphism UI** - Modern glass effect components
- ⚡ **Smooth Animations** - Powered by Framer Motion and GSAP
- 📱 **Fully Responsive** - Mobile, tablet, and desktop optimized
- 🚀 **Production Ready** - Clean architecture and modular components

## 🛠️ Tech Stack

- **React 18** - UI framework
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first CSS
- **Framer Motion** - Animation library
- **GSAP** - Advanced animations
- **React Router DOM** - Client-side routing
- **Lucide React** - Icon library

## 📦 Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```
